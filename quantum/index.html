QUICK START

Get started with Topoi Quantum.

1. Install the SDK

Topoi Quantum requires the .NET 10 SDK. Add the core package to your .NET project: 

dotnet add package Topoi.Quantum --version 0.1.0

If your application needs OpenQASM 3 parsing, execution or export, add the OpenQASM package: 

dotnet add package Topoi.Quantum.OpenQasm --version 0.1.0

For command-line and interactive use, install the tq .NET tool globally: 

dotnet tool install --global Topoi.Quantum.Tool --version 0.1.0
tq --help

2. Create your first circuit

Create a Bell-state circuit using the Topoi Quantum C# API. 

using Topoi.Quantum;
using Topoi.Quantum.Primitives;

QuantumCircuit bell = QuantumToolkit
    .Circuit(2)
    .H(0)
    .CX(0, 1)
    .Build();

More examples, package details and API information are available in the project repository.
